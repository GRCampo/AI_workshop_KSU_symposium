The severity scores and the VI values are in separate files. The first step is to merge them and how you ask for that turns out to matter more than you think.

<div class="prompt-ladder">

<div class="prompt-step">
  <p class="prompt-step-head"><span class="prompt-step-number">1</span> The first thing most people write (probably)</p>
  <p class="prompt-step-context">Both files are named, the goal is clear, and the request is one sentence.</p>
</div>

```text title="Prompt 1 — merge and correlate"
I have two files. Data/DataS6.csv has disease severity scores and Data/DataS7.csv
has NDVI and OSAVI from drone images of the same trial.

Merge them and calculate the correlation between NDVI and disease severity.
```

<div class="prompt-step">
  <p class="prompt-step-head"><span class="prompt-step-number">2</span> Asking what has to happen first</p>
  <p class="prompt-step-context">Same data, same goal. The difference is that this one does not ask for the answer yet.</p>
</div>

```text title="Prompt 2 — inspect before joining"
I have a raspberry field trial scored for late leaf rust.

Data/DataS6.csv has one row per plot, with severity scored by eye at four dates
(Sev11 to Sev17, in days after inoculation).
Data/DataS7.csv has one row per plot per flight, with NDVI and OSAVI from drone
imagery, and a column pheno giving the time point.

I want to test whether NDVI and OSAVI decrease as visual severity increases, at
each scoring date separately.

Before writing any code: open both files and tell me what has to be resolved
before these two tables can be joined. List what you find, including anything
that would silently change the number of rows. Do not write code yet.
```
