<p><strong>Before any tool is opened, you have to decide what the analysis is for.</strong></p>

Here are some questions that this data can answer.

<div class="hypothesis-grid">

  <div class="incident-card path-card--b">
    <div class="incident-body">
      <p>Vegetation indices separate resistant from susceptible plots before visual symptoms.</p>
    </div>
  </div>

  <div class="incident-card path-card--b">
    <div class="incident-body">
      <p>Genotypes differ in the rate at which severity increases, not only in final severity.</p>
    </div>
  </div>

  <div class="incident-card path-card--b">
    <div class="incident-body">
      <p>Spatial correction improves the prediction of severity from vegetation indices.</p>
    </div>
  </div>

  <div class="incident-card path-card--b">
    <div class="incident-body">
      <p>AUDPC separates slow-rusting genotypes that a single-date severity score would miss.</p>
    </div>
  </div>

</div>

Every one of these is a reasonable question, and an AI assistant will write code for any of them without hesitating. That is the point: **the model does not choose the question, and it will not tell you that you chose the wrong one.**
