## Which path is yours

<p><span class="path-badge path-badge--a">Path A:</span> If the computer is your own.</p>
<p><span class="path-badge path-badge--b">Path B:</span> If your computer was issued by the university or by a company, and you cannot install software yourself.</p>

<p>If you are not sure: look for "Company Portal" in your applications list.</p>

<p>These are two alternatives. <strong>FOLLOW ONE OF THEM, NOT BOTH.</strong></p>

<div class="incident-card path-card--a">
  <div class="incident-header">
    <div class="incident-heading">
      <p class="path-badge path-badge--a">Path A</p>
      <p class="incident-title">For a computer you own</p>
    </div>
  </div>
  <div class="incident-body">
    <ol>
      <li>Go to the Visual Studio Code download page: <a href="https://code.visualstudio.com/Download">https://code.visualstudio.com/Download</a></li>
      <li>Download the installer for your operating system (The site usually detects it for you).</li>
      <li>On Windows:</li>
      <ol>
        <li>Run the installer as a user, not as an administrator.</li>
        <li>Keep the “Add to PATH” option checked (default).</li>
      </ol>
      </ol>
  </div>
</div>

<p class="path-or">or</p>

<div class="incident-card path-card--b">
  <div class="incident-header">
    <div class="incident-heading">
      <p class="path-badge path-badge--b">Path B</p>
      <p class="incident-title">For a machine managed by IT</p>
    </div>
  </div>
  <div class="incident-body">
    <ol>
      <li>Open Company Portal.</li>
      <li>Go to Apps and search for Visual Studio Code.</li>
      <li>Click Install and wait.</li>
      <li>If Visual Studio Code is not in the catalogue, open a ticket with your IT service desk.</li>
    </ol>
  </div>
</div>
