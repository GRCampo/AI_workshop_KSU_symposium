## Before the workshop

Work down this list. Each item links to the page that sets it up.

<ol>
	<li><strong> Visual Studio Code is installed.</strong> Not yet? Go to `Tutorials >` [Visual Studio Code](/AI_workshop_KSU_symposium/before-workshop/installation-tutorial/)</li>
    <li><strong>R and Python are both installed.</strong> Not yet? Go to `Tutorials >` [Two ways to run R in VS Code](/AI_workshop_KSU_symposium/before-workshop/two-ways-to-run-r/)</li>
	<li><strong>Jupyter is installed? Both the VS Code extension and the Python package.</strong> Not yet? Go to `Tutorials >`[Installing Jupyter](/AI_workshop_KSU_symposium/before-workshop/installing-jupyter/)</li>
	<li><strong>An R kernel is registered and shows up in the kernel picker.</strong> Not yet? Go to `Tutorials >`[Create an R kernel for Jupyter](/AI_workshop_KSU_symposium/before-workshop/r-kernel-jupyter/)</li>
</ol>

<strong>If all four are true, YOU ARE READY!</strong>
<p>Do this before the day of the workshop, not on the morning of it. If something breaks, you will want time to sort it out.</p>
